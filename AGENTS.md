# Repository Guide

## Language

Write repository content, code comments, commit messages, issues, and pull requests in English.

## Pull Requests

- Use a topic branch and pull request; do not push implementation changes directly to `main`.
- Write pull request titles and bodies in English.
- Follow `.github/pull_request_template.md` without removing or renaming its sections, and replace every placeholder with repository-specific content.
- Run the relevant validation and conformance checks documented by this repository before delivery.
